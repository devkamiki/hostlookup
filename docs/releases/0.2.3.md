# HostLookup 0.2.3

This release makes lookups faster and keeps them running if you leave the app.

- Shows DNS records as soon as the provider comparison finishes, then loads
  network details in the background.
- Keeps an in-progress lookup running after you switch away, with a quiet
  status notification.
- Asks fewer duplicate resolver endpoints, so the comparison finishes sooner.
- Fills in location from RIPEstat MaxMind, RIPEstat geoloc, DB-IP, and
  ipwho.is when an earlier source has no country.

Android 8.0 or newer and a supported 64-bit CPU are required. DNS queries use
public resolvers, including unencrypted UDP/TCP. Network enrichment uses
RIPEstat, and DB-IP or ipwho.is only when RIPEstat has no country.
