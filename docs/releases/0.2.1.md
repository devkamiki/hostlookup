# HostLookup 0.2.1

This release prepares HostLookup for F-Droid packaging and fixes installation
compatibility on unsupported 32-bit devices.

- Compiles the Android certificate verifier from pinned upstream Kotlin source,
  with its licenses included.
- Ships native code only for ARM64 and x86_64, matching the supported Rust targets.
- Locks Rust dependency resolution and verifies the Gradle distribution checksum.
- Adds store descriptions, real device screenshots, and clearer DNS/network
  service disclosures.

Android 8.0 or newer and a supported 64-bit CPU are required. DNS queries use
public resolvers, including unencrypted UDP/TCP; network enrichment uses RIPEstat.

The preparation build was tested on an Android 16 ARM64 device with eindhoven.nl:
DNS results, provider switching, record details, and network enrichment worked.
Release lint and local F-Droid source/APK scans passed for the preparation build.
These checks do not constitute acceptance into F-Droid or an isolated fdroiddata
build. F-Droid submission is still pending.
