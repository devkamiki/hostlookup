# HostLookup 0.2.2

This release localizes HostLookup to follow the device language.

- Translates the interface into Simplified Chinese, Traditional Chinese,
  Dutch (Netherlands and Belgium), US and UK English, French, German,
  Japanese, and Korean.
- Adds matching F-Droid store listings for those locales.
- Lets Android 13 and newer pick the app language in system settings.

Android 8.0 or newer and a supported 64-bit CPU are required. DNS queries use
public resolvers, including unencrypted UDP/TCP; network enrichment uses RIPEstat.
